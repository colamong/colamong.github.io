# 볼트 노트 → 블로그 글

노트 한 편을 글로 만들어 저장소에 넣습니다. **원격 push 는 하지 않습니다** — 사용자가 직접 합니다.

| 단계 | 하는 주체 |
|---|---|
| 노트 고르기 | 사용자 또는 Orchestrator |
| 초안 만들기 | `post-editor` 서브에이전트 |
| 저장·검사·빌드 | 이 스킬 (스크립트) |

`post-editor` 가 초안 텍스트만 돌려주고 쓰기는 여기서 합니다. 에이전트가 저장소에 직접 쓰면 검사를 건너뛸 경로가 생깁니다.

## 절차

### 1. 노트 고르기

사용자가 노트를 지정하지 않으면 후보를 보여주고 묻습니다. 여러 편을 한 번에 만들지 않습니다.

```bash
ls "$HOME/Documents/Obsidian Vault/04_Patterns"
```

`04_Patterns` 가 1순위입니다. 이미 일반화가 끝나 있어 사내 맥락을 걷어낼 일이 적습니다. `02_Projects` 는 사내 고유명사가 많아 손이 많이 갑니다.

### 2. 초안 받기

`post-editor` 서브에이전트를 부릅니다. 넘길 것:

- 노트 **경로** (내용을 프롬프트에 통째로 붙이지 않습니다)
- 오늘 날짜
- 이미 있는 글 목록 (제목·대분류가 겹치는지 판단하도록)

돌아온 텍스트를 그대로 씁니다. frontmatter 를 임의로 고치지 않습니다 — 고칠 것이 있으면 `post-editor` 에게 다시 맡깁니다.

### 3. 저장

파일명은 영문 kebab-case 입니다. 제목을 그대로 옮기지 않습니다 — URL 이 됩니다.

```bash
# src/content/posts/<slug>.md
```

같은 이름이 이미 있으면 덮어쓰지 않고 사용자에게 묻습니다.

### 4. 검사

```bash
npm run lint
```

두 가지가 돕니다.

| 검사 | 막는 것 |
|---|---|
| `secret_lint.py` | 금칙어, AWS 키·토큰·개인키 패턴, 내부 주소, 이메일 |
| `post_lint.py` | 그림 0개, 3 스크롤 초과 |

**막히면 고쳐서 통과시킵니다. 검사를 끄지 않습니다.**

- 그림이 없다 → `post-editor` 에게 그림을 요청합니다
- 3 스크롤 초과 → 줄이거나 두 편으로 나눕니다. 나눈 글끼리 링크로 잇습니다
- 기밀에 걸렸다 → 해당 줄을 일반화합니다. 목록에서 빼지 않습니다

> `금칙어 목록이 없어 건너뛴다` 경고가 뜨면 `orc/_local/blog-denylist.txt` 가 없는 것입니다. **발행 전에 만듭니다.** 목록 없이는 형식 검사만 돌아서, 통과가 안전을 뜻하지 않습니다.

### 5. 빌드로 확인

```bash
npm run build
```

종료 코드 0 을 눈으로 확인합니다. `prebuild` 가 검사를 다시 돌리므로 여기서 막히면 4단계로 돌아갑니다.

### 6. 화면으로 확인

```bash
npm run preview   # http://localhost:4321
```

- 홈 목록에 제목·배지·날짜·한 마디가 제대로 붙었는지
- 글 안 그림이 본문 폭에 맞는지
- 다크 모드에서 그림 선이 보이는지 (`currentColor` 를 안 썼으면 안 보입니다)

### 7. 보고

발행하지 않고 멈춥니다. 사용자에게 알립니다.

> `<제목>` 을 `src/content/posts/<slug>.md` 에 넣었습니다. 검사 통과, 빌드 통과, N 스크롤, 그림 M개. push 는 안 했습니다.

## 검증

- [ ] `npm run build` 종료 코드 0
- [ ] `post_lint` 에 그림 1개 이상, 3 스크롤 이하로 표시
- [ ] `secret_lint` 가 금칙어 목록을 실제로 읽었다 (건너뜀 경고가 없다)
- [ ] 제목에 공백이 있고 파일명형이 아니다
- [ ] 대분류가 셋 중 하나다
- [ ] 미리보기에서 라이트·다크 양쪽을 봤다

## 하지 않을 것

- 원격 저장소에 push — 사용자가 직접 합니다
- 검사를 끄거나 `draft: true` 로 바꿔 통과시키기 (초안으로 두는 것과 회피는 다릅니다)
- 한 번에 여러 편 발행
- 사이트 코드 고치기 — `astro-expert` 담당입니다
- 볼트 원본 노트 수정
